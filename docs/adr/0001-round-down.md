# 0001. 会員割引の端数切り捨て

- ステータス: 承認
- 決定日: 2026-07-15
- 決定者: 要確認（議事録に決定者の明記なし）
- 根拠資料: `docs/minutes.md` 16-20行目、`docs/design.md` 15・31・42行目

## 背景

会員割引は、セール品を除いた商品合計の10%として計算する。金額は整数の円で扱うため、割引額に1円未満の端数が生じた場合の処理を定める必要がある。

## 検討した選択肢

- 端数を切り上げる
- 端数を切り捨てる

## 決定

会員割引の端数は切り捨てる。割引対象商品の合計に10%を掛け、その結果に `Math.floor` を適用して整数の円にする。

## 結果

- 良い面: 端数を切り上げた場合に生じる1円単位の問い合わせを避けられる。
- 悪い面: 割引額は正確な10%を1円未満下回る場合がある。
- どちらでもない面: 会員割引の対象はセール品を除いた商品合計とし、クーポンや送料の計算規則は変更しない。
