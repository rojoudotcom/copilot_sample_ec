# 設計書: カート料金計算

- 対象: `src/pricing.ts`
- 版: 2026-07-22 時点の現行仕様

---

## 1. 技術設計

| 項目 | 内容 |
|------|------|
| 言語 | TypeScript（strict モード・`any` 禁止） |
| 配置 | 料金計算は `src/pricing.ts` の純粋関数に置く（外部 I/O に依存しない） |
| テスト | Vitest（`src/pricing.test.ts`） |
| 金額 | すべて整数（円）。端数は `Math.floor` で切り捨てる |
| 異常系 | `PricingError` を throw する（`null` や `-1` で表現しない） |

## 2. データモデル

| 型 | 主なフィールド |
|----|---------------|
| `CartItem` | `id` / `name` / `unitPrice` / `quantity` / `onSale` |
| `Cart` | `items` / `isMember` / `couponCode`（任意） |
| `PricingResult` | `subtotal` / `memberDiscount` / `couponDiscount` / `shippingFee` / `total` |

## 3. 機能設計

| 機能 | 入力 | 出力・振る舞い |
|------|------|---------------|
| 小計の算出 | `Cart` | 単価 × 数量 の合計 |
| 会員割引の算出 | `Cart` | 会員のみ、セール品を除いた合計の10%（切り捨て） |
| クーポン割引の算出 | `Cart` | `SAVE500` で500円引き。会員割引との併用は不可 |
| 送料の算出 | 割引後の金額 | 5,000円以上で0円、未満で500円 |
| 合計の算出 | `Cart` | 小計 − 会員割引 − クーポン割引 ＋ 送料 |

## 4. 受け入れ条件

### 正常系

- [ ] 小計が「単価 × 数量」の合計になる
- [ ] 会員割引はセール品を除外した合計に対して10%になる
- [ ] 会員割引の端数は切り捨てになる
- [ ] クーポン `SAVE500` で500円引きになる
- [ ] 割引後の金額が5,000円未満のとき、送料500円が加算される
- [ ] 割引後の金額が**ちょうど5,000円**のとき、送料は無料になる
- [ ] カートが空のとき、合計は0円になる（送料も加算しない）

### 異常系

- [ ] 数量が0以下のとき `PricingError` を投げる
- [ ] 単価がマイナスのとき `PricingError` を投げる
- [ ] 無効なクーポンコードのとき `PricingError` を投げる
- [ ] 会員割引とクーポンを併用しようとしたとき `PricingError` を投げる

## 5. 対象外

- 消費税の内税・外税の切り替え
- 離島・一部地域の追加送料
- 会員ランク別の割引率
- ポイントの付与・利用
