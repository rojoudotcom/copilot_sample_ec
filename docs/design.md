# 設計書: カート料金計算

- 対象: `src/pricing.ts`
- 基準: `docs/requirements.md`（2026-10-08）

---

## 1. 技術設計

| 項目 | 設計 | 選定理由 |
|------|------|----------|
| 言語 | TypeScript（strict モード、`any` 禁止） | 入力・出力の型を固定し、料金計算の取り違えを防ぐため |
| 配置 | `src/pricing.ts` の純粋関数として実装し、外部 I/O を行わない | 同じ入力から同じ結果を得られ、計算を単体で検証できるため |
| テスト | Vitest を使い、`src/pricing.test.ts` に記述する | プロジェクトで採用済みのテスト環境に合わせるため |
| 金額 | すべて整数（円）で扱い、会員割引額は `Math.floor` で切り捨てる | 要件の整数金額と割引端数処理を一貫して実現するため |
| 異常系 | `PricingError` を throw し、計算結果を返さない | 無効クーポンと割引併用エラーを正常な金額と区別し、購入手続きへの継続を防ぐため |

## 2. データモデル

| 型 | 主なフィールド |
|----|---------------|
| `CartItem` | `unitPrice: number`（単価・円） / `quantity: number`（数量） / `onSale: boolean`（セール品か） |
| `Cart` | `items: CartItem[]` / `isMember: boolean` / `couponCode?: string` |
| `PricingResult` | `subtotal: number` / `memberDiscount: number` / `couponDiscount: number` / `shippingFee: number` / `total: number`（すべて円） |

## 3. 機能設計

| 機能 | 入力 | 出力・振る舞い |
|------|------|---------------|
| 小計の算出 | `Cart.items` | 各商品の `unitPrice * quantity` を合計し、小計を返す |
| 会員割引の算出 | `Cart` | 会員の場合、セール品を除いた商品の合計の10%を割り引く。割引額の小数部分は切り捨てる。非会員の場合、割引額は0円 |
| クーポン割引の算出 | `Cart.couponCode` | `SAVE500` の場合は500円を割り引く。未入力の場合は割引額0円。未定義のコードは `PricingError` とする |
| 割引の併用判定 | `Cart.isMember` / `Cart.couponCode` | 会員割引とクーポンが同時に指定された場合は `PricingError` とする |
| 送料の算出 | 小計から会員割引またはクーポン割引を引いた金額 | 割引後金額が5,000円以上なら0円、5,000円未満なら500円 |
| 合計の算出 | `Cart` | 小計 − 会員割引 − クーポン割引 ＋ 送料を返す。商品がない場合は各金額と合計を0円とする。割引後金額が0円未満になる場合の扱いは確認事項とする |

## 4. 受け入れ条件

### 正常系

- [ ] 単価1,000円、数量2の商品1点を含むカートの小計は2,000円になる
- [ ] 会員の通常商品合計が1,000円の場合、会員割引は100円になる
- [ ] 会員の通常商品合計が1,001円の場合、会員割引は100円になる
- [ ] 会員カートに通常商品1,000円とセール品1,000円がある場合、会員割引は通常商品分の100円になる
- [ ] クーポンコード `SAVE500` を指定した場合、クーポン割引は500円になる
- [ ] 割引後金額が4,999円の場合、送料は500円になる
- [ ] 割引後金額が5,000円の場合、送料は0円になる
- [ ] 割引後金額が5,001円の場合、送料は0円になる
- [ ] 商品がないカートの場合、送料と合計はいずれも0円になる

### 境界値

- [ ] 通常商品5,554円の会員カートでは、割引額は555円、割引後金額は4,999円、送料は500円になる
- [ ] 通常商品5,555円の会員カートでは、割引額は555円、割引後金額は5,000円、送料は0円になる
- [ ] `SAVE500` 適用前の金額が5,499円の場合、適用後金額は4,999円、送料は500円になる
- [ ] `SAVE500` 適用前の金額が5,500円の場合、適用後金額は5,000円、送料は0円になる
- [ ] 通常商品1,001円の会員カートでは、割引額は100円となり、小数部分0.1円は切り捨てられる

### 異常系

- [ ] 未定義のクーポンコード `UNKNOWN` を指定した場合、`PricingError` が発生し、料金計算結果を返さず購入手続きに進めない
- [ ] 会員でクーポンコード `SAVE500` も指定した場合、`PricingError` が発生し、料金計算結果を返さず購入手続きに進めない

## 5. 対象外

- 消費税の内税・外税の切り替え
- 離島・一部地域の追加送料
- 会員ランク別の割引率
- ポイントの付与・利用
- 商品入力値の検証方法
- エラー表示の具体的な方法
- クーポンの有効期限と複数枚利用
- クーポン適用後に金額が0円未満になる場合の扱い

## 6. 提案

- 要件にないラッピング料金や商品入力値の検証を継続する場合は、仕様と受け入れ条件を要件定義書に追加してから設計へ反映する。
- クーポン適用後に金額が0円未満になる場合の扱いは、販売企画の確認後に要件と受け入れ条件へ追加する。
