# カート料金計算 要件ヒアリング 議事録

- 日時: 2026-07-15（水）14:00〜15:00
- 出席: 販売企画（依頼元）／開発リーダー／QA
- 目的: EC サイトのカート料金計算について、現行仕様の確認と積み残しの洗い出し

---

## 1. 決まっていること

### 小計

- 小計は「単価 × 数量」をカート内の全商品で合計した金額とする。
- 金額はすべて整数（円）で扱う。小数は画面にも API にも出さない。

### 会員割引

- 会員は小計から10%引き。
- **セール品は会員割引の対象外**。セール品と通常商品が混在する場合、通常商品の合計にだけ10%を掛ける。
- 割引額に端数が出た場合は**切り捨て**る。販売企画から「切り上げると1円単位で問い合わせが来るため、必ず切り捨てにしてほしい」と要望あり。

### クーポン

- 今回対応するのはコード `SAVE500`（500円引き）の1種類のみ。
- **会員割引とクーポンは併用できない**。併用しようとした場合はエラーとして扱い、購入手続きに進ませない。
- 無効なコードが入力された場合もエラーとする。

### 送料

- 割引後の金額が **5,000円以上で送料無料**。5,000円未満は一律500円。
- 「5,000円ちょうど」は無料に含める（QA から明示の依頼あり）。
- 送料無料の判定は、会員割引・クーポンを適用した**後**の金額で行う。

### カートが空の場合

- 商品が1件も入っていない場合、合計は0円とする。送料も加算しない。

---

## 2. 決まっていないこと（この場では結論が出なかった）

- **消費税の扱い**。現行は税込単価で計算しているが、税抜表示への切り替え要望が別部署から出ているらしい。今回のスコープに含めるかは要確認。
- **離島・一部地域の追加送料**。物流側と調整中で、金額も条件も未定。
- クーポンの**有効期限**と、1回の購入で複数枚使えるかどうか。販売企画が持ち帰り。

---

## 3. 今回はやらないこと

- 会員ランク（シルバー・ゴールド等）による割引率の出し分け。次フェーズで検討する。
- ポイント付与・ポイント利用。別システムの担当のため本件では扱わない。
